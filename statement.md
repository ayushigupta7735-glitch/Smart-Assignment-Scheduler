# Problem Statement

## Problem
Students often handle several assignments at the same time. Deadlines, priority levels,
and different amounts of required work make it difficult to decide what should be done first.
A simple list of assignments does not always communicate which task needs immediate attention.

## Proposed Solution
Smart Assignment Scheduler is a Java console application that stores assignment details and
generates a priority-based schedule. It considers deadline urgency, assignment priority,
and estimated workload to arrange pending tasks.

## Scope
The project covers assignment creation, viewing, scheduling, completion tracking, deletion,
summary generation, validation, and file-based persistence.

## Target Users
The primary users are college and school students who need a lightweight way to organize
academic assignments.

## High-Level Features
- Add and store assignments.
- Validate assignment information.
- View all assignments.
- Generate a smart priority schedule.
- Mark assignments as completed.
- Delete assignments.
- Display completion statistics.
- Persist data using a text file.
